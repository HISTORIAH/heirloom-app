Refinements in This Preview

Full color system preserved

Pink (create), Lime (active), Cyan (time), Yellow (heirs), Orange (claimable/urgent), Purple (guardian), Red (emergency).

Color shadows match cards

Pink card → pink shadow. Cyan card → cyan shadow. Reinforces the color language.

Fixed button sizing

Both hero buttons are h-14 (56px) with equal padding. Visual weight difference comes from fill vs outline, not size.

Single hero highlight

Only "assets" is pink. "Pass it on trustlessly" is plain black. No color competition.

Countdown, not ECG

Clean digits. "Vault Status" not "Vault Monitor". "Check In" not "Send Heartbeat".

Flow Fixes
1

Create vault: Heir → Deposit → Heartbeat → Review

Emotional anchor first, then tangible, then technical.

2

Deposit step: Tabs for SOL / Tokens

Token list with search, sort, dust filter, virtual scroll for 1k+ tokens.

3

Dashboard: Status + Countdown king

Assets in tabs. Heir/Details collapsible. Actions grouped.

4

Claim/Signer/Defer: Auto-scan

No manual address typing. Wallet is the lookup key. Silent inheritance preserved.

5

Yield strategies: Lulo + Staking

Cyan border for Lulo yield. Lime border for staking. "Earn" / "Recall" actions. Only shown when yield is available for that token.

6

"Edit Settings" → "Update Estate"

Accurate name. Pencil icon, not gear. Covers interval, grace, pause, and label.
