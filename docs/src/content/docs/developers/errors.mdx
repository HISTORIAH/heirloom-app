The clients decode these by name.

| Error | Raised when | Fix |
|---|---|---|
| `Unauthorized` | The signer isn't the role the instruction needs | Connect the right wallet |
| `NotYetClaimable` | A claim before the deadline, or during a guardian pause | Wait |
| `MintMismatch` | A mint doesn't match the account it's used with | Rebuild the instruction |
| `MissingTokenAccounts` | A token call without its token, treasury or record accounts | Pass the full account set |
| `InsufficientVaultBalance` | Nothing left of that asset | Already claimed or returned |
| `AlreadyDeferred` | A second guardian pause | One pause until the owner checks in after it ends |
| `DeferWindowExpired` | A guardian pause once claimable | Too late. Only the owner can act |
| `MismatchedAddress` | The guardian passed doesn't match the stored one | Check the account list |
| `EstatePaused` | Changing the heir during a guardian pause | Wait for the pause to end, check in, retry |
| `InvalidAccount` | A token account or heir-change target that doesn't belong to the estate | Rebuild the instruction |
| `ZeroDepositAmount` | A deposit of zero | Pass a positive amount |
| `TokensFirst` | The SOL call ran before the token calls | Tokens first, SOL last |
| `MathOverflow` / `MathUnderflow` | Checked arithmetic failed | Usually a malformed amount |
| `IntervalTooLong` | A timing value above 365 days | Reduce it |
| `IntervalNegative` | A negative timing value | Use zero or more |
| `FundsStillDeployed` | Claim, revoke or heir change on an asset in Lulo | The owner recalls the position first |

## Other errors you may see

| Symptom | Usually |
|---|---|
| `AccountNotInitialized` | No estate exists for that owner and heir |
| `ConstraintSeeds` | An address derived from the wrong owner or heir |
| Opening fails right after closing | The network hasn't caught up yet. Wait and retry |
| A transfer fails on one token | The account is frozen, or the token has an active transfer hook |
