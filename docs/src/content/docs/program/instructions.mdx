Eleven instructions. No admin instruction exists.

## The set

| Instruction | Signer | What it does |
|---|---|---|
| `initialize` | Authority | Creates the estate and vault, optionally registers a first mint, moves opening deposits in |
| `register_asset` | Authority | Creates an `AssetRecord` and vault token account for a mint, and deposits |
| `update_field` | Authority **or** `hb_signer` | Writes `last_heartbeat`. Applies settings only for the authority |
| `update_heir` | Authority | Migrates the estate to a new PDA pair for a new heir, one asset per call |
| `claim` | Heir | Pays out one asset to the heir, minus 0.75% |
| `revoke` | Authority | Returns one asset to the authority, minus 0.5% |
| `delegate_defer` | `delegate` | Sets `paused_until` to `now + pause_duration`, once |
| `deposit_lulo` | Authority | Routes an amount into a Lulo pool, protected or boosted |
| `withdraw_protected_lulo` | Authority | Recalls a protected position |
| `init_withdraw_regular_lulo` | Authority | Phase one of a boosted withdrawal |
| `complete_withdraw_regular_lulo` | Authority | Phase two of a boosted withdrawal |

## Notes that matter when you call these

### `update_field` is both the heartbeat and the settings editor

It writes `last_heartbeat = now` unconditionally, *then* applies the optional arguments —
and only if the signer is the authority. Pass all four as `None` and it is a pure
heartbeat. Pass settings as a hot signer and they are silently ignored while the heartbeat
still lands.

It is also the only instruction that clears `paused_until`, and only when the pause has
already expired.

### `claim` and `revoke` are per-asset

Each call moves one asset. The SOL leg closes the vault, so it must come last:
`claimable_assets <= 1` is required before the SOL branch will run, otherwise
`TokensFirst`. Bundle token instructions first and the SOL instruction last in one
transaction.

Both also require the asset's `AssetRecord` to show no live exposure and no pending
boosted withdrawal, or they fail with `FundsStillDeployed`.

### `update_heir` is a multi-call migration

One asset per call, with the new estate carrying `is_migrating: true` until the last one
lands. Run it to completion.

### Optional accounts

`initialize` takes `delegate`, `hb_signer`, `mint`, `vault_token_account`,
`authority_token_account` and `asset_record` as optional accounts. Omitting the mint
group opens a SOL-only estate; omitting `delegate` or `hb_signer` leaves those roles
unset for the life of the estate.

</Callout>
