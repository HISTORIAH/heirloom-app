You can add assets to a live estate at any time from the owner wallet. There is no
protocol fee and no limit on how often.

## What you can add

SOL and any SPL token, from both the classic Token program and Token-2022. NFTs and
compressed assets aren't supported.

The first time a token goes into an estate it is registered, which costs a little rent
for its accounts. You get that back when the estate closes. After that, adding more of
the same token is a plain transfer.

## Tokens that need care

<Callout type="danger" title="Freeze authority">
If a token's issuer freezes the estate's account for it, that asset is stuck until they
unfreeze it. Most regulated stablecoins, USDC and USDT included, have this power. It is a
property of the token, and no program can work around it.
</Callout>

- **Transfer hooks.** A token with an active transfer hook is rejected when you add it.
  If an issuer turns a hook on after you added the token, that asset can't leave.
- **Transfer fees.** A token that charges a fee on transfer simply arrives a little
  smaller.

## Good to know

- **Adding assets is not a check-in.** Only a check-in or a timing change resets the
  clock, so a busy estate can still run out.
- **To take assets back,** [close the estate](/docs/using/close-estate/). The app returns
  everything at once.
