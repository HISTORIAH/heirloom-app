An heir doesn't have to be another person. Name a **second wallet you control** and the
estate becomes a way back into your own assets.

## How it works

You check in from your main wallet as usual. If you lose it, the check-ins stop. Once
your interval and grace period run out, your backup wallet claims the estate. No seed
phrase is ever shared and no one else is involved.

The cost is the waiting time and the 0.75% claim fee.

## Setting it up

Create an estate as normal and name your backup wallet as the heir.

<Callout type="tip" title="Keep the two wallets apart">
Use a different device, a different seed phrase and a different place. A backup stored
next to the main wallet won't help if you lose both together.
</Callout>

## Choosing the timing

For recovery, shorter is usually better, because the interval is how long you are locked
out. But the same window is how long a stolen backup key has to wait before it can take
everything.

A good balance is a short interval with a longer grace: you notice a missed check-in
quickly, and still have time to get the main wallet back before the backup can act.

## Limits

- **Losing both keys.** There is no third way in.
- **A stolen backup key.** Whoever holds it can claim once the deadline passes. Protect
  it like the main one.
- **Assets outside the estate.** Only what is in the estate can be recovered.

## Recovery and inheritance

One estate has one heir, so you can't do both in one. Open two: one naming your backup
wallet with a short clock, and one naming a person with a longer one.
