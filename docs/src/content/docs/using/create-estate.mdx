Creating an estate takes four choices and one signature. Start at
[app.heirlm.xyz/create-vault](https://app.heirlm.xyz/create-vault) with a wallet
connected. That wallet becomes the owner.

## 1. Heir

The wallet that can claim once the deadline passes. One estate has one heir, and the
estate is tied to that address, so check it twice. You can
[change it later](/docs/using/change-heir/).

To recover your own wallet rather than leave assets to someone, name a second wallet of
yours. See [Wallet recovery](/docs/using/wallet-recovery/).

## 2. Assets

SOL, tokens, or both. This is only an opening balance: you can
[add more](/docs/using/fund-estate/) whenever you like. Check
[which tokens need care](/docs/using/fund-estate/#tokens-that-need-care) before adding
anything unusual.

## 3. Timing

| Setting | What it means | Limit |
|---|---|---|
| Check-in interval | How long you can go without checking in | 365 days |
| Grace period | Extra time after a missed check-in, before the heir can claim | 365 days |
| Pause length | How far a guardian can push the deadline, once | 365 days |

All three can be changed later, and changing them counts as a check-in. For help
choosing, see [Check in](/docs/using/check-in/#choosing-your-timing).

You can also name two optional helpers here: a **guardian** who can pause the deadline
once, and a **check-in signer** that can check in for you. Neither can move funds, and
neither can be changed after creation yet. See [How it works](/docs/how-it-works/#who-can-do-what).

## 4. Review and sign

The review screen shows the estate exactly as it will exist. Read the timing back in
days, confirm the heir, and sign.

One transaction creates the estate and moves every asset in. Either all of it happens or
none of it does. The clock starts the moment it lands.

## If it fails

| Error | Cause |
|---|---|
| `IntervalTooLong` | A setting above 365 days |
| `ZeroDepositAmount` | An asset added with an amount of zero |
| "Prior estate/vault PDAs not yet cleared on-chain" | You just closed an estate for the same heir. Wait a few seconds and retry |
