For any program error by name, see [Errors](/docs/developers/errors/).

### "Wallet not connected"

The action needs a signer. Connect a wallet and try again.

### "Prior estate/vault PDAs not yet cleared on-chain"

You just closed an estate and are creating a new one for the same heir. The network
hasn't caught up yet. Wait a few seconds and retry.

### My heir can't claim yet (`NotYetClaimable`)

The deadline hasn't passed, or a guardian's pause is still running. The claim page shows
the countdown.

### `FundsStillDeployed`

An asset is in a Lulo position, or a boosted withdrawal was started and not finished.
The owner has to recall it first. The heir can't.

### Adding one particular token fails

The token has an active transfer hook, which can't go into an estate, or its issuer has
frozen the account. See [Fund an estate](/docs/using/fund-estate/#tokens-that-need-care).

### Tokens show as addresses, with no icons

The app couldn't load token names and icons. Your estate and its balances are
unaffected.

### A check-in from the phone page is rejected

The connected wallet isn't the estate's check-in signer. The page shows the registered
signer under the result, so compare the two.

### An estate doesn't appear on the claim page

The page lists estates that name the connected wallet. If yours is missing, the owner
named a different address, or you are on the wrong network.

### Still stuck

Open an issue on [GitHub](https://github.com/HISTORIAH/Heirloom-app) with the failing
transaction signature, or email **hey@heirlm.xyz**.
