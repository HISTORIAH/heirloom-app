## RPC

The app needs a **DAS-capable** endpoint for token metadata — symbols and icons come from
the Helius DAS API served off the same RPC URL. Against a plain public RPC the DAS calls
fail and the UI falls back to truncated mint addresses; nothing else is affected.

```ini
VITE_SOLANA_RPC_ENDPOINT=https://devnet.helius-rpc.com/?api-key=<KEY>
VITE_SOLANA_SUBSCRIPTIONS_RPC_ENDPOINT=wss://devnet.helius-rpc.com/?api-key=<KEY>
```

With neither set, the app targets a local validator at `127.0.0.1:8899`.
