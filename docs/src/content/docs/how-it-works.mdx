Heirloom has one moving part: **a deadline you push forward by checking in.** Everything
else follows from it.

## The deadline

An estate becomes claimable at:

```txt
last check-in + check-in interval + grace period
```

Each check-in resets the starting point, so as long as you keep checking in, the heir
can never claim. A 30-day interval with a 7-day grace means the heir can claim 37 days
after your last check-in, and not a second before.

If a guardian has paused the estate, the deadline is the later of that time and the end
of the pause.

## The four states

| State | When | What can happen |
|---|---|---|
| **Active** | Within your check-in interval | Everything. Only you can act |
| **Grace** | Interval missed, grace still running | The same, and the app warns you. A guardian can pause it |
| **Claimable** | Grace has run out | The heir can claim. You can still take everything back first |
| **Claimed** | The estate is empty | Nothing. The estate is closed |

Nothing happens on its own. A claimable estate waits, indefinitely and at no cost, until
the heir signs.

## Who can do what

Every estate has an **owner** (the wallet that opened it) and an **heir**. It can also
name two optional helpers:

- **Guardian:** someone you trust who can pause the deadline once, for when you are fine
  but can't check in. See [Pause as a guardian](/docs/using/defer/).
- **Check-in signer:** a second wallet of yours, usually on your phone, that can check
  in and nothing else. It lets the owner key stay on a hardware wallet.

| | Owner | Heir | Guardian | Check-in signer |
|---|---|---|---|---|
| Check in | ✓ | | | ✓ |
| Change timing | ✓ | | | |
| Add assets, earn yield | ✓ | | | |
| Change the heir | ✓ | | | |
| Close the estate | ✓ | | | |
| Pause the deadline, once | | | ✓ | |
| Claim, once claimable | | ✓ | | |

The owner can never change. The heir can be [changed](/docs/using/change-heir/). The
guardian and check-in signer are set when the estate is created and can't be changed
yet; to change them, close the estate and open a new one.

## One estate, one heir

Every asset in an estate goes to the one heir it names. To split an inheritance, open
one estate per person and fund each with what they should get.

## How assets leave

| Exit | Who | Fee |
|---|---|---|
| [Close the estate](/docs/using/close-estate/) | You, any time before it is claimed | 0.5% |
| [Claim](/docs/using/claim/) | The heir, once claimable | 0.75% |
| [Change the heir](/docs/using/change-heir/) | You. Assets move to a new estate, not a wallet | Free |

Once an estate is claimable, both you and the heir can act. Whoever signs first wins.
