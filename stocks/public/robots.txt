# https://stocks.heirlm.xyz — the landing at the root is public; every other
# route is the wallet-gated app, per-user and noindex. The main site,
# https://heirlm.xyz, serves its own robots.txt and sitemap.
#
# Crawling is left fully open on purpose. The old allow-list (Allow: /$ …
# Disallow: /) kept crawlers from ever seeing the app routes' noindex, and a
# disallowed URL linked from elsewhere can still be indexed without its content.
# The app routes are kept out of search by noindex instead: an X-Robots-Tag
# header on each route in _headers, plus the robots meta that Seo.tsx sets. The
# landing renders client-side, so the bundle, catalog, icons and share card all
# have to be fetchable too, which an open file guarantees.

Allow: /
